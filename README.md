# SQA Sprint

An interactive, structured learning roadmap for becoming job-ready in **Software Quality Assurance (SQA)**.

I built SQA Sprint as a practical study companion focused on the skills commonly required for entry-level and junior QA roles, particularly in the Bangladesh software industry.

Rather than being just a collection of notes, it organizes the learning process into a progressive **200-hour curriculum** with concepts, hands-on practice, interview preparation, and self-check drills.

## What It Covers

- Software Testing Foundations
- Manual Testing Concepts
- Test Case Design
- Bug Reporting
- SDLC & STLC
- Agile & Scrum
- Testing Tools
- SQL from Fundamentals to Advanced
- Database Validation
- API Testing
- Postman
- Python for QA
- Playwright Automation
- Page Object Model
- Automation Framework Concepts
- CI/CD Basics
- Operating System Fundamentals
- Networking Fundamentals
- QA Interview Preparation

## Curriculum

The roadmap contains:

- **200 hours** of structured learning
- **31 modules**
- **160+ interview questions**
- **55 self-check flashcards**
- Hands-on exercises throughout the roadmap

## Learning Structure

Topics are divided into stages so that the roadmap can be followed progressively.

Each module is also marked by priority:

- **Must Master** — essential for QA roles
- **Must Know** — important working knowledge
- **Should Know** — useful supporting knowledge
- **Awareness** — concepts worth being familiar with

This makes it easier to prioritize limited study time.

## Hands-On Focus

SQA Sprint is designed around learning by implementation rather than only reading theory.

The roadmap includes practical work involving:

- Writing test cases
- Designing test scenarios
- Reporting bugs
- SQL querying
- Database validation
- API testing
- Python scripting
- Browser automation
- Playwright
- Page Object Model
- Basic automation pipelines

## Interview Preparation

A dedicated interview-preparation layer is included throughout the curriculum.

It currently contains:

- **160+ interview questions**
- Frequently tested QA concepts
- Technical questions
- SQL questions
- API testing questions
- Automation questions
- Quick revision material

## Drill Mode

SQA Sprint also includes a dedicated **Drill** system with flashcards for concepts that need to be memorized or recalled quickly.

The current version contains **55+ drill flashcards** collected from across the curriculum.

## Why I Built It

While learning Software Quality Assurance, I wanted a single roadmap that answered three questions:

1. What should I learn?
2. In what order should I learn it?
3. How deeply should I learn each topic?

SQA Sprint is my attempt to turn that roadmap into an interactive learning system instead of maintaining scattered notes, bookmarks, and checklists.

The project will continue evolving as I progress through SQA, automation, backend development, and software engineering concepts.

## Target

The roadmap is primarily designed for preparation for roles such as:

- Software Quality Assurance Engineer
- Junior SQA Engineer
- Manual QA Engineer
- API QA Engineer
- QA Automation Engineer
- Software Tester

It also includes additional SQL and data-validation material useful for QA-heavy data roles.
